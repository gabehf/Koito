# Multiuser screenshots

These are unedited screenshots of Koito's compiled interface running on a new,
disposable SQLite database. Alex Demo, Jamie Demo, Sam Demo, all listening
records and geometric artwork were created solely for demonstration. No existing
user database, photos, music-server connection or browser profile was used.
The displayed external URL uses the reserved `.example` domain and the token is
an explicit demonstration placeholder. Browser requests were restricted to the
local demonstration server. No real external relay was configured or contacted.

- `01-profile-selection.png`: public profile selection at `/`.
- `02-profile-dashboard.png`: one profile's listening dashboard.
- `03-profile-selector.png`: sidebar profile selector.
- `04-profile-administration.png`: profile management inside Settings.
- `05-profile-forwarding.png`: per-profile forwarding controls inside Settings.

Captured at 1440 × 900 with an isolated headless Chrome context. The original
Koito appearance, branding and development-version label are preserved.
